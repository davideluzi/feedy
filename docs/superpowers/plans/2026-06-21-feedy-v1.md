# Feedy v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a simple native macOS RSS reader ("Feedy") with a Mail-style three-column UI: feed list, article list with read/unread state, and a consistently-styled article view.

**Architecture:** SwiftUI + SwiftData app (macOS 14+). A pure, unit-testable core (feed parsing, HTML sanitization, article import/dedup, article rendering) sits behind protocols so it is testable without UI. FeedKit normalizes RSS/Atom/JSON; SwiftSoup sanitizes article HTML once at fetch time and the cleaned HTML is persisted. A `WKWebView` renders the cleaned HTML inside a single bundled CSS template so every article looks identical. Images are loaded on-the-fly (not cached). Refresh happens on launch and on demand only.

**Tech Stack:** Swift, SwiftUI, SwiftData, WKWebView, FeedKit (SPM), SwiftSoup (SPM), XCTest.

**Note on FeedKit/SwiftSoup API drift:** FeedKit's public API changed across major versions. All FeedKit-specific code is isolated in ONE adapter file (`FeedKitParser.swift`) behind the `FeedParsing` protocol, so version differences touch only that file. If the installed FeedKit API differs from the code shown, adapt only that adapter — the rest of the codebase depends on our own `ParsedFeed`/`ParsedArticle` types.

```swift
import Foundation
import CryptoKit

protocol FeedParsing {
    /// Parse raw feed bytes into our normalized model.
    func parse(data: Data, sourceURL: URL) throws -> ParsedFeed
}

enum ArticleIdentity {
    /// Stable per-article key: guid ?? link ?? hash(title + publishedDate).
    static func key(for article: ParsedArticle) -> String {
        if let g = article.guid, !g.isEmpty { return g }
        if let l = article.link, !l.isEmpty { return l }
        let basis = (article.title ?? "") + "|" + (article.publishedDate?.description ?? "")
        let digest = SHA256.hash(data: Data(basis.utf8))
        return digest.map { String(format: "%02x", $0) }.joined()
    }
}
```

- [ ] **Step 4: Write minimal implementation**

Create `Feedy/Core/FeedKitParser.swift`. The code below targets FeedKit's classic enum-based API (`FeedParser(data:).parse()` returning `Result<Feed, ParserError>`, `Feed` being `.rss/.atom/.json`). **If the installed FeedKit version differs, adapt only this file** — map whatever FeedKit returns into `ParsedFeed`/`ParsedArticle`:

```swift
import Foundation
import FeedKit

struct FeedKitParser: FeedParsing {
    enum ParseError: Error { case unrecognizedFormat }

    func parse(data: Data, sourceURL: URL) throws -> ParsedFeed {
        let result = FeedParser(data: data).parse()
        switch result {
        case .failure(let error):
            throw error
        case .success(let feed):
            switch feed {
            case .rss(let rss):    return mapRSS(rss)
            case .atom(let atom):  return mapAtom(atom)
            case .json(let json):  return mapJSON(json)
            }
        }
    }

    private func mapRSS(_ f: RSSFeed) -> ParsedFeed {
        let items = (f.items ?? []).map { item in
            ParsedArticle(
                guid: item.guid?.value,
                link: item.link,
                title: item.title,
                author: item.author ?? item.dublinCore?.dcCreator,
                publishedDate: item.pubDate,
                contentHTML: item.content?.contentEncoded ?? item.description ?? ""
            )
        }
        return ParsedFeed(title: f.title, siteURL: f.link, articles: items)
    }

    private func mapAtom(_ f: AtomFeed) -> ParsedFeed {
        let items = (f.entries ?? []).map { entry in
            ParsedArticle(
                guid: entry.id,
                link: entry.links?.first?.attributes?.href,
                title: entry.title,
                author: entry.authors?.first?.name,
                publishedDate: entry.published ?? entry.updated,
                contentHTML: entry.content?.value ?? entry.summary?.value ?? ""
            )
        }
        return ParsedFeed(title: f.title, siteURL: f.links?.first?.attributes?.href, articles: items)
    }

    private func mapJSON(_ f: JSONFeed) -> ParsedFeed {
        let items = (f.items ?? []).map { item in
            ParsedArticle(
                guid: item.id,
                link: item.url,
                title: item.title,
                author: item.author?.name,
                publishedDate: item.datePublished,
                contentHTML: item.contentHtml ?? item.contentText ?? ""
            )
        }
        return ParsedFeed(title: f.title, siteURL: f.homePageURL, articles: items)
    }
}
```

- [ ] **Step 4: Write minimal implementation**

Create `Feedy/Core/HTMLSanitizer.swift`. Targets SwiftSoup's `Cleaner` + `Whitelist`/`Safelist` API. **If the installed SwiftSoup names a type `Safelist` instead of `Whitelist`, swap the type name here only:**

```swift
import Foundation
import SwiftSoup

struct SanitizedContent {
    var html: String
    var plainText: String
}

struct HTMLSanitizer {
    func sanitize(html: String, baseURL: String) throws -> SanitizedContent {
        // Parse with a base URI so relative URLs can be made absolute.
        let dirty = try SwiftSoup.parse(html, baseURL)

        // Build an allowlist of semantic tags + the attributes we keep.
        let allow = try Whitelist.relaxed()
            .addTags("figure", "figcaption", "h1", "h2", "h3", "pre")
            .preserveRelativeLinks(false)   // emit absolute href/src

        let cleaner = Cleaner(allow)
        let clean = try cleaner.clean(dirty)
        clean.outputSettings().prettyPrint(pretty: false)

        // Rewrite remaining relative URLs to absolute (belt-and-suspenders).
        for el in try clean.select("[href]") {
            let abs = try el.absUrl("href"); if !abs.isEmpty { try el.attr("href", abs) }
        }
        for el in try clean.select("[src]") {
            let abs = try el.absUrl("src"); if !abs.isEmpty { try el.attr("src", abs) }
        }

        let cleanedHTML = try clean.body()?.html() ?? ""
        let plain = try clean.text()
        return SanitizedContent(html: cleanedHTML, plainText: plain)
    }
}
```

```swift
struct ArticleImporter {
    let sanitizer: HTMLSanitizing

    @MainActor
    func importArticles(_ parsed: [ParsedArticle], into feed: Feed,
                        context: ModelContext) throws {
        // Index existing articles of this feed by identity key.
        var existing: [String: Article] = [:]
        for article in feed.articles { existing[article.identityKey] = article }

        for p in parsed {
            let key = ArticleIdentity.key(for: p)
            let base = p.link ?? feed.siteURL ?? feed.url
            let clean = try sanitizer.sanitize(html: p.contentHTML, baseURL: base)

            if let current = existing[key] {
                // Update mutable fields; NEVER touch isRead.
                current.title = p.title ?? current.title
                current.author = p.author
                current.link = p.link
                current.publishedDate = p.publishedDate
                current.bodyHTML = clean.html
                current.bodyPlainText = clean.plainText
            } else {
                let article = Article(
                    identityKey: key,
                    title: p.title ?? "(untitled)",
                    author: p.author,
                    link: p.link,
                    publishedDate: p.publishedDate,
                    bodyHTML: clean.html,
                    bodyPlainText: clean.plainText
                )
                article.feed = feed
                context.insert(article)
                existing[key] = article
            }
        }
        try context.save()
    }
}
```

```swift
import Foundation

enum ArticleRenderer {
    /// Pure document builder (testable).
    static func document(title: String, bodyHTML: String, css: String) -> String {
        """
        <!doctype html>
        <html>
        <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <style>\(css)</style>
        </head>
        <body>
        <h1>\(escape(title))</h1>
        \(bodyHTML)
        </body>
        </html>
        """
    }

    /// Convenience that loads the bundled stylesheet.
    static func document(title: String, bodyHTML: String) -> String {
        let css = loadCSS()
        return document(title: title, bodyHTML: bodyHTML, css: css)
    }

    static func loadCSS() -> String {
        guard let url = Bundle.main.url(forResource: "article", withExtension: "css"),
              let s = try? String(contentsOf: url, encoding: .utf8) else { return "" }
        return s
    }

    private static func escape(_ s: String) -> String {
        s.replacingOccurrences(of: "&", with: "&amp;")
         .replacingOccurrences(of: "<", with: "&lt;")
         .replacingOccurrences(of: ">", with: "&gt;")
    }
}
```

```swift
struct URLSessionFetcher: FeedFetching {
    func fetch(url: URL) async throws -> Data {
        var request = URLRequest(url: url)
        request.setValue("Feedy/1.0", forHTTPHeaderField: "User-Agent")
        let (data, response) = try await URLSession.shared.data(for: request)
        if let http = response as? HTTPURLResponse, !(200...299).contains(http.statusCode) {
            throw URLError(.badServerResponse)
        }
        return data
    }
```

```swift
import Foundation
import SwiftData

struct FeedRefreshService {
    let fetcher: FeedFetching
    let parser: FeedParsing
    let importer: ArticleImporter

    @MainActor
    func refresh(_ feed: Feed, context: ModelContext) async throws {
        guard let url = URL(string: feed.url) else {
            feed.lastErrorMessage = "Invalid URL"; try context.save(); return
        }
        do {
            let data = try await fetcher.fetch(url: url)
            let parsed = try parser.parse(data: data, sourceURL: url)
            if let t = parsed.title, !t.isEmpty, feed.title.isEmpty { feed.title = t }
            if feed.siteURL == nil { feed.siteURL = parsed.siteURL }
            try importer.importArticles(parsed.articles, into: feed, context: context)
            feed.lastErrorMessage = nil
            feed.lastFetchDate = .now
            try context.save()
        } catch {
            // Non-blocking: record the error, keep existing articles.
            feed.lastErrorMessage = error.localizedDescription
            feed.lastFetchDate = .now
            try context.save()
        }
    }

    /// Refresh many feeds with bounded concurrency (max 5 at a time).
    @MainActor
    func refreshAll(_ feeds: [Feed], context: ModelContext) async {
        let chunks = stride(from: 0, to: feeds.count, by: 5).map {
            Array(feeds[$0..<min($0 + 5, feeds.count)])
        }
        for chunk in chunks {
            await withTaskGroup(of: Void.self) { group in
                for feed in chunk {
                    group.addTask { @MainActor in try? await self.refresh(feed, context: context) }
                }
            }
        }
    }
}
```

```swift
    @Environment(\.modelContext) private var context
    let selection: SidebarSelection
    @Binding var selectedArticle: Article?
    @Binding var showOnlyUnread: Bool
    @Binding var searchText: String

    @Query private var feeds: [Feed]

        return nil

        return base
```

## Deferred (explicitly NOT in v1)

These are intentionally out of scope; the architecture already accommodates them:
1. **Full-text extraction (step B)** — download the original page and extract readable content for truncated feeds. Plugs into the same sanitize→render pipeline; only the HTML source changes.
2. **Feed discovery** — paste a homepage URL, find its feed (`<link rel="alternate">` + common paths). Reuses step B's fetch+parse-HTML code.
3. **User-defined folders/groups** of feeds.
4. **Background refresh** while the app is closed (`BGTaskScheduler`).
5. **Full-text body search** — search the already-persisted `bodyPlainText` field (cheap upgrade).
6. **Image caching / remote-tracking-pixel blocking** (privacy toggle).
7. **DB cleanup policy** — prune saved bodies for old/read articles or removed feeds. Add when volume grows; not blocking for v1.
8. **Favicon fetching** for the sidebar (currently a system glyph placeholder).
