Installation

The first launch takes one extra step. You only do it once.

  1. Download Feedy using the button above.
  2. Drag Feedy into your Applications folder.
  3. Double-click Feedy. macOS will show a warning saying the app can't be opened: click Done (or OK).
  4. Open System Settings → Privacy & Security and scroll to the bottom. Next to the message about Feedy, click Open Anyway.
  5. Confirm with Open Anyway and enter your Mac password (or use Touch ID).

That's it. From now on Feedy opens normally, like any other app.

Why the warning?

Feedy is an independent project and isn't distributed through the Apple Developer Program, so it isn't “notarized” by Apple. macOS blocks apps like this on first launch as a precaution. It doesn't mean the app is damaged or unsafe.

Don't see the “Open Anyway” button?

You can unblock the app from Terminal. Open Terminal (in Applications → Utilities), paste this command and press Return:

xattr -dr com.apple.quarantine /Applications/Feedy.app

Then open Feedy as usual. The same command also fixes the “Feedy is damaged and can't be opened” message.
